# Outprint

Outprint es una app web estática para buscar desde el navegador libros agotados, raros o difíciles de encontrar.

## Cómo usarla en el browser

No necesitas instalar nada ni crear un ZIP.

1. Abre `index.html` directamente con Chrome, Edge, Firefox o Safari.
2. Escribe el título del libro. Si lo tienes, agrega autor, ISBN, editorial o año para que la búsqueda sea más precisa.
3. Presiona **Buscar en el navegador**.
4. La app abrirá una búsqueda web precisa en una nueva pestaña del browser.
5. Si quieres comparar manualmente, también puedes usar las tarjetas de AbeBooks, Biblio, eBay, Amazon, WorldCat y Google Books.

## Desarrollo

```bash
npm test
```

Valida que la app tenga los buscadores recomendados, el botón principal y la lógica de precisión.
